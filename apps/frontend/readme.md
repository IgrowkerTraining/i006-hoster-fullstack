## inciar aplicacion

1. crear archivo `.env` en la carpeta `apps/frontend`
2. agregar la siguiente variable de entorno:
```
VITE_API_BASE_URL=https://i006-hoster-fullstack-develop.onrender.com/api
```
3. instalar dependencias con el comando:
```
npm install
```

4. iniciar la aplicacion con el siguiente comando:
```
npm run dev
```
